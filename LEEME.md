# Elite Football 3D V19 — acceso libre temporal

Abre index.html desde un servidor web o utiliza el HTML autónomo.

Se ha retirado temporalmente el acceso privado, Google y el bloqueo horario. No hay acceso al antiguo panel de administración ni a los datos privados de administrador. La ficha de jugador, récords, preferencias y partidas se guardan localmente sin registro. La V18 original conserva sus mecanismos de autenticación y configuración de horarios; los datos anteriores del administrador no se borran ni se copian al perfil público.

Se mantienen las escenas, jugadores, botas, balones, música, personalización y tres modos de juego de la V18. Los archivos del motor y recursos son idénticos a la V18.
